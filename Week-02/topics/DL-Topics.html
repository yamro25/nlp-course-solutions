Task 0: Initialization Methods in Neural Networks

1. Importance of Weight Initialization

In deep neural network optimization, weight initialization is crucial for controlling signal flow, preventing early training instability, and speeding up convergence. Arbitrary or ill-conditioned initialization induces two primary failure modes:

  • Vanishing Gradients: When weights are initialized too small ($W \ll 1$), activations shrink across successive forward layers, and backpropagated gradients decay to near zero, stopping early layers from updating.
  • Exploding Gradients: When weights are initialized too large ($W \gg 1$), layer outputs and backward gradients grow exponentially with depth, causing numerical overflow and divergent oscillations.

The goal is Variance Preservation: ensuring that the variance of activations and gradients remains approximately constant across layers:

$$\mathrm{Var}(z^{[l]}) \approx \mathrm{Var}(z^{[l-1]}) \quad \text{and} \quad \mathrm{Var}\left(\frac{\partial \mathcal{L}}{\partial z^{[l]}}\right) \approx \mathrm{Var}\left(\frac{\partial \mathcal{L}}{\partial z^{[l+1]}}\right)$$

2. Initialization Techniques

A. Zero Initialization

Sets all weights $W_{ij} = 0$. This results in complete network symmetry; every neuron computes identical activations and receives identical gradients during backpropagation, failing to extract diverse features. Zero initialization should only be used for biases.

B. Standard Random Initialization

Samples weights from a fixed normal or uniform distribution (e.g., $W \sim \mathcal{N}(0, 0.01^2)$). While it breaks symmetry, it does not scale with the fan-in ($n_{in}$), causing vanishing or exploding signals in deeper networks ($L > 5$).

C. Xavier / Glorot Initialization

Designed for symmetric, zero-centered linear and quasi-linear activations (Tanh, Sigmoid, Softmax):

$$\text{Normal: } W \sim \mathcal{N}\left(0, \frac{2}{n_{in} + n_{out}}\right) \qquad \text{Uniform: } W \sim \mathcal{U}\left(-\sqrt{\frac{6}{n_{in} + n_{out}}}, +\sqrt{\frac{6}{n_{in} + n_{out}}}\right)$$

Limitation: Fails with ReLU-like activations because discarding negative values halves the signal variance per layer.

D. He / Kaiming Initialization

Formulated specifically for rectified units (ReLU, Leaky ReLU, PReLU) by doubling the assigned variance to account for inactive negative regimes:

$$\text{Normal: } W \sim \mathcal{N}\left(0, \frac{2}{n_{in}}\right) \qquad \text{Uniform: } W \sim \mathcal{U}\left(-\sqrt{\frac{6}{n_{in}}}, +\sqrt{\frac{6}{n_{in}}}\right)$$

E. LeCun Initialization

Focuses on preserving variance in the forward pass assuming zero-centered inputs: $W \sim \mathcal{N}\left(0, \frac{1}{n_{in}}\right)$. When paired with SELU, it provides mathematical self-normalization.

الشرح والتوضيح بالعربي (Task 0)

  • أهمية تهيئة الأوزان: في الشبكات العميقة، الأوزان الكبيرة تؤدي إلى انفجار التدرج (Exploding Gradients) وتوقف التدريب، والأوزان الصغيرة جداً تؤدي إلى تلاشي التدرج (Vanishing Gradients) وانعدام التعلم. الهدف الأساسي هو الحفاظ على تباين الإشارة (Variance) ثابتاً في مساري الحساب الأمامي والخلفي.
  • Zero Initialization: وضع الأوزان بصفر يجعل كل الخلايا تحسب وتتعلم نفس القيم بدون أي تمايز، لذلك تستخدم فقط للـ Biases.
  • Random Initialization: اختيار قيم عشوائية صغيرة يكسر التماثل لكنه يفشل مع زيادة عمق الشبكة لأنه لا يراعي عدد المدخلات ($n_{in}$).
  • Xavier / Glorot: مخصصة لدوال التنشيط المتماثلة مثل Tanh و Sigmoid، ولكنها تسبب تلاشي الإشارة مع عائلة ReLU.
  • He / Kaiming: مصممة خصيصاً لـ ReLU ومشتقاتها؛ تعوض فقدان الإشارات السالبة عبر مضاعفة التباين لضمان استقرار الشبكات العميقة جداً.
  • LeCun: الأساس الرياضي لشبكات التنظيم الذاتي عند استخدامها مع دالة SELU.

Task 1: The ReLU Family of Activation Functions

1. Standard ReLU

$$f(x) = \max(0, x), \quad f'(x) = \begin{cases} 1 & \text{if } x > 0 \\ 0 & \text{if } x < 0 \end{cases}$$

ReLU resolves vanishing gradients for positive activations and avoids computationally intensive exponentials. However, it suffers from the Dying ReLU problem: neurons with negative inputs output zero and have zero gradient, causing irreversible deactivation.

2. Variants of the ReLU Family

A. Leaky ReLU

$$f(x) = \begin{cases} x & \text{if } x > 0 \\ \alpha x & \text{if } x \le 0 \end{cases} \quad (\text{typically } \alpha = 0.01)$$

Introduces a fixed small slope $\alpha$ for negative values, allowing gradients to flow and eliminating dead neurons with minimal computation.

B. Parametric ReLU (PReLU)

$$f(x) = \max(0, x) + a \min(0, x)$$

Treats the negative slope $a$ as a learnable parameter optimized during backpropagation, dynamically tailoring the response per channel/layer.

C. Randomized ReLU (RReLU)

Samples negative slope values from a uniform distribution during training ($a \sim \mathcal{U}(l, u)$) and uses the expected mean during inference, acting as a built-in regularizer.

D. Exponential Linear Unit (ELU)

$$f(x) = \begin{cases} x & \text{if } x > 0 \\ \alpha(e^x - 1) & \text{if } x \le 0 \end{cases}$$

Provides smooth, non-zero negative outputs that push the mean activation closer to zero, accelerating gradient descent and improving noise robustness at the cost of exponential computations.

E. Scaled Exponential Linear Unit (SELU)

$$f(x) = \lambda \begin{cases} x & \text{if } x > 0 \\ \alpha(e^x - 1) & \text{if } x \le 0 \end{cases} \quad (\lambda \approx 1.0507, \, \alpha \approx 1.6733)$$

Induces self-normalizing properties in deep MLPs, automatically stabilizing mean and variance across layers without Batch Normalization.

F. ReLU6

$$f(x) = \min(\max(0, x), 6)$$

Clamps positive activations to a maximum of 6.0, which prevents activation values from overflowing in low-precision (INT8/FP16) embedded and mobile deployments (e.g., MobileNet).

G. Gaussian Error Linear Unit (GELU)

$$f(x) = x \cdot \Phi(x) \approx 0.5x \left(1 + \tanh\left(\sqrt{\frac{2}{\pi}}\left(x + 0.044715 x^3\right)\right)\right)$$

Gates inputs probabilistically based on their cumulative normal distribution value. It provides smooth non-monotonicity and is the standard activation for modern Transformer architectures (BERT, GPT, ViT).

الشرح والتوضيح بالعربي (Task 1)

  • دالة ReLU: الأشهر بفضل سرعتها وحلها لمشكلة تلاشي التدرج للقيم الموجبة، ولكن يعيبها مشكلة موت الخلايا (Dying ReLU) للقيم السالبة.
  • Leaky ReLU: تضيف ميلاً بسيطاً (مثل $0.01$) للمنطقة السالبة لمنع موت الخلايا.
  • PReLU: تجعل الميل السالب معاملاً قابلاً للتعلم أثناء التدريب (Learnable Parameter).
  • ELU: تستخدم دالة أسية للقيم السالبة لتقريب متوسط المخرجات من الصفر وتسريع التدريب.
  • SELU: نسخة مطورة بثوابت دقيقة تمنح الشبكة ميزة التنظيم الذاتي (Self-Normalization) بدون الحاجة إلى Batch Normalization.
  • ReLU6: تحد المخرجات بحد أقصى $6$ لتسهيل حسابات التكميم (Quantization) للأجهزة المحمولة والـ Embedded Systems.
  • GELU: تعتمد على التوزيع الطبيعي وتتميز بالنعومة وعدم وجود انكسار حاد، وهي الدالة القياسية في نماذج الـ Transformers الحديثة.
